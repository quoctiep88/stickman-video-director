# Computing Clearly — Series bible supplement

For future Computing Clearly drafts, read this with `productions/computing-clearly/SERIES.md`. The accepted P05 approval includes that local bible's exact bytes.

Speak calmly to an intelligent beginner. Be curious, clear and slightly informal. Start with something familiar on screen. Explain jargon when the listener needs the word. An occasional genuine question can carry the thought forward. Give the diagram room to answer. Skip routine section recaps, sales pitches, dramatic reveals and childish comparisons.
