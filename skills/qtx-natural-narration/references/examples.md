# Examples

**Introduce a term.** “A cache is a mechanism for retaining data for future access.” → “The app keeps a copy, so it can use it again. That copy goes in a cache.” The listener has a reason to care about the name.

**Let the picture work.** Over a diagram of a message arriving, “The arrow moves across the screen to indicate that the message arrives at the server.” → “Now the server has the message. What did the app ask for?” The question carries us into the contents of the message.

**Find the breath.** “If the file is missing when the app tries to open it, the app displays an error indicating that it couldn't find the file.” → “The app tries to open the file. If it's missing, you'll see an error.” The pause comes at the point where the outcome can change.
